# Credits

Vimny doesn't have an in-game credits screen yet. Until it does, this file is the
record — if you build a credits screen, source it from here.

## Latin mottos — victory banners

The victory banners (`main.py`: `_fireworks_animation` and `_starfield_victory`)
use Latin mottos:

- **VIM PROMOVET INSITAM** — shown on a par-perfect (non-boss) finish.
  From **Horace** (Quintus Horatius Flaccus), *Odes* 4.4.33–34:
  *"doctrina sed vim promovet insitam, / rectique cultus pectora roborant"* —
  "but training draws out the inborn force; right cultivation strengthens the
  heart." We quote the half-line *vim promovet insitam* ("[training] develops the
  inborn force"), which doubles as wordplay on **Vim**, the editor (Latin *vim* is
  the accusative of *vīs*, "force / vigor / energy").

- **VIM AD ASTRA** — shown on completing a boss level.
  Our own coinage: *vim* (force/vigor — and the editor) + the proverbial *ad
  astra* ("to the stars"). "Ad astra" is a common classical tag rather than any
  one author's line, so no single source is credited. For the curious, compare
  **Virgil**, *Aeneid* 9.641 (*"sic itur ad astra"*, "thus one goes to the
  stars"), and **Seneca the Younger**, *Hercules Furens* 437 (*"non est ad astra
  mollis e terris via"*, "there is no easy road from earth to the stars"). The
  phrasing *vim ad astra* as used here is original to this game.
